# Phase 0 Implementation Plan

> **For agentic workers:** Execute inline with superpowers:executing-plans.

**Goal:** Create a private research repository with a tested app inspector and native JIT probe.
**Architecture:** Inspection is read-only and independent of the future execution engine.
Native ARM64 code executes only our own JIT instructions; Intel fixtures are inspected only.
**Tech Stack:** Python 3.11+, C++17, Apple Clang, CMake, Ninja.
**Spec:** `docs/superpowers/specs/2026-10-13-phase0-design.md`

## Global Constraints

- macOS ARM64; Xcode Command Line Tools; Python 3.11 or later.
- Do not change SIP/AMFI or attach restricted entitlements.
- Do not upload commercial binaries, activation data or user documents.
- Upstreams and generated raw reports stay in ignored local directories.
- CPU translation and commercial application execution remain unverified.

## Review Focus

- Truncated or malicious load commands must raise a controlled parse error.
- Universal binaries must preserve all slice architectures and validate bounds.
- Symlinks must not cause inspection outside the app bundle.
- A JIT test must establish native execution and correct return values.
- An Intel fixture must not accidentally be executed through Rosetta.
